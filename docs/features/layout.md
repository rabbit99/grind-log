# 版面、頁籤與表格捲動

## 目的

讓頁面在手機、平板、筆電、寬螢幕上都不會溢出，而且改／刪一直按得到。

## 頁籤

- 標題下方的 `#pageTabs` 切換整個頁面：「練功記錄」`#pageMain`、「每日進度」`#pageDaily`、「練功計畫」`#pagePlan`（`#tabPlan`，見 [plan.md](plan.md)）。
- 選擇會記住，存在 `grind-log/v1:ui` 的 `tab`（`main`／`daily`／`plan`）。
- 無障礙：`role="tablist"`／`tab`／`tabpanel`、`aria-selected`；三個頁籤都適用。
  - 只有目前的頁籤在 Tab 鍵順序裡，其他頁籤用左右方向鍵、Home、End 切換。
- 切換時捲回頁面最上方。

## 寬度分界

| 寬度 | 練功記錄頁 | 每日進度頁 | 練功計畫頁 |
|---|---|---|---|
| 901px 以上 | 兩欄：左欄 320px（表單、檔案，sticky），右欄放表格 | 表格 | 單欄面板；條件表單最寬 640px；排程表是一般表格（`#tblPlan`，放不下時在 `.scroll` 裡左右捲） |
| 900px 以下 | 單欄：表單在上，表格在下；左欄不再 sticky | 每天一張卡片 | 表單滿版；時段的開始／結束時間欄位平分寬度；排程表改成每時段一張卡片（比照每日進度頁：日期／星期／時段／時數 加單位，目標與位置各佔一行） |

**320～360px 的頁籤**：三個頁籤在 320px 寬會被擠成兩行（高度 60px，把頁面往下推），所以 `@media(max-width:360px)` 內把頁籤的左右內距縮到 6px 並禁止換行，讓三個頁籤維持一行、高度跟只有兩個頁籤時相同（39px）。375px 以上不受影響。

練功計畫頁的 CSS 全部限定在 `#pagePlan` 底下，**沒有改動練功記錄、每日進度兩頁在 901px 以上的任何元素**，只在 `#pageTabs` 多了一個頁籤按鈕。

**901px 以上的桌面版外觀，沒有使用者同意不要改**。

## 表格左右捲與固定欄

- 每張表格都包在 `.scroll{overflow-x:auto}` 裡，而且 `.cols > *{min-width:0}`。表格比欄位寬時，在自己的區塊裡左右捲，**不會把整頁撐寬**。
- **固定欄**：記錄、人員、等級三張表的最後一欄是 `.act`（改／刪）。表格需要左右捲時：
  - 程式（`scrollRO`，一個 ResizeObserver）在 `.scroll` 上加 `is-scroll`。
  - 這時 `.act` 固定在右側（`position:sticky`），有底色，左邊加分隔線。
  - 「改／刪」一直顯示，不必等滑鼠移過去。
  - 停用的列，固定格本身不透明，改成按鈕變淡；否則捲到下面的內容會透出來。
  - 加上 `scroll-padding-right:56px`：用 Tab 移動焦點時，輸入框不會停在固定欄底下。
- 表格放得下時不加 `is-scroll`，外觀跟沒有固定欄一樣。
- **判斷方式**：
  - 先拿掉 `is-scroll` 再量 `scrollWidth > clientWidth`，量完把捲動位置放回去。
    - 帶著 `is-scroll` 量的話，備註欄的最小寬度會讓表格一直判斷成要捲，縮小再放大後就退不回來。
    - 拿掉的那一下捲動位置會被夾小，所以要放回去。
  - 判斷排到下一格畫面（`requestAnimationFrame`）才做，避免 ResizeObserver loop 警告。
- **記錄表的寬度**：
  - 格子內距 6px，最窄約 834px，1280px 以上的視窗放得下。
  - 表格要捲、而且這一頁有兩個字以上的備註時（`has-note`），備註欄最少 10em，避免被擠成一行一個字。

## 窄螢幕的細節

- 面板標題旁的提示文字自己換行，不把標題擠成兩行。
- 分頁列放不下時整段換行，「每頁」不會被壓成直的。
- 很長又沒有空白的文字都能折行，不會撐寬頁面，包括：
  - 標題（可以從匯入的 JSON 帶進來）。
  - 經驗條和每日進度頁的圖例。
  - 訊息 `.msg`。
- 折行用 `overflow-wrap:anywhere`，並以 `word-break:break-word` 當舊瀏覽器的退路。
- 觸控螢幕（`hover:none`）上，記錄表的「改／刪」一直顯示。

## 設計決策

- **使用者選的方案（C）**：修 901～1300px 溢出時，保留兩欄版面，只把記錄表縮窄，需要捲時固定改／刪。
  - 以前曾經讓表格直接縮窄，結果「改」按鈕被捲到看不到，使用者抱怨過。
- **每日進度頁是整頁切換**：使用者要求不改動原本記錄頁的版面。

## 相關程式

CSS 的 layout、tables、分頁、每日進度頁區段；`scrollRO`、`applyTab()`、頁籤的 keydown 和 click 事件。

## 修改時要檢查

- 320、375、414、600、768、900、901、1000、1280、1600px 寬度，三個頁籤都不溢出（舊兩頁與 main 逐元素相同，只多一個頁籤按鈕）。
- 901px 以上，除了這次要改的地方，其他元素的位置和大小要跟 main 相同。
- 需要捲的寬度下，改／刪固定在右側而且點得到；縮小再放大後要能退出固定狀態；捲到右邊時改變視窗寬度不會跳動。
- **預覽窗格被隱藏時，ResizeObserver 不會觸發**，要用可見的 Electron 視窗測試，見 [development.md](../development.md#測試方法)。
