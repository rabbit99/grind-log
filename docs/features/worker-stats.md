# 人員效率表

## 目的

比較不同人員（例如主要角色與第二個角色）的效率，啟用「計費與成本」模組時也比較成本。

## 介面

「練功記錄」頁右欄第一個面板「人員效率」`#tblWorkers`。欄位：人員、時數、獲得%、獲得經驗、每小時經驗、每小時%、費用、每百萬經驗成本；最後一列是合計。**「費用」「每百萬經驗成本」兩欄與標題旁的價格提示，只在「計費與成本」模組開啟時顯示**（見 [cost-module.md](cost-module.md)）；隱藏只影響顯示，數字照常計算。

## 行為規則

- 算法見 [calculations.md](../calculations.md#人員效率表)。只計算啟用的記錄，時數用計費時數。
- 只列出有時數的人員。沒有任何資料時顯示「尚無資料」。
- 每小時經驗最高的標綠色。
- 每百萬經驗成本在有費用的人員之間比較，最低標綠色、最高標紅色。
  - 沒有費用（不計費的人員）或沒有經驗時顯示「—」。
  - 合計列只有總經驗是 0 時顯示「—」，總費用是 0 時顯示「0」。

## 設計決策

- **看「每百萬經驗成本」，不看「每 1% 成本」**：不同等級的 1% 經驗量不同，只有用經驗值計算的成本才能跨等級比價。標題旁的提示就是在說這件事。

## 邊界情況

- 找不到人員的記錄（人員被刪掉）不會出現在這張表。它們的費用是 0（時薪要靠人員資料），經驗仍計入經驗條。
