# 記一筆時段（新增、修改）

## 目的

登錄一個練功時段：什麼時候、誰練、幾級、獲得多少 %。也用來修改已經登錄的記錄。

## 介面

「練功記錄」頁左欄上方「記一筆時段」：

| 欄位 | id | 說明 |
|---|---|---|
| 日期 | `#f-date` | 開機時預設今天。目前是用 UTC 日期，台灣時間早上 8 點前會變成前一天，見 [tech-debt.md](../tech-debt.md) |
| 起、迄（時） | `#f-start`、`#f-end` | 小時制，可以填小數（10.5 = 10:30）；範圍 0～24 |
| 人員 | `#f-worker` | 人員名單，可能有「（找不到這位人員：id）」的選項，見下方 |
| 計費時數 | `#f-bh` | 只有選到計費的人員時才顯示；留空代表跟時段一樣；placeholder 顯示時段長度 |
| 等級 | `#f-level` | 整數 |
| 獲得 % | `#f-pct` | 可以是負數，例如死亡掉經驗 |
| 備註 | `#f-note` | |

按鈕：「新增記錄」／「儲存修改」`#btnSave`、「取消編輯」`#btnCancel`；訊息 `#formMsg`。

桌面版的左欄會黏在畫面上（sticky），可以自己捲動；900px 以下改成一般排列，放在記錄表上面。

## 行為規則

### 驗證（依序檢查，遇到第一個錯誤就停）

1. 沒選日期 →「選一個日期」。
2. 起或迄不是數字 →「填起迄時間」。
3. 起 = 迄 →「起迄時間不能相同」。
4. 沒有人員：有人員時是「選一位人員」，完全沒有人員時是「先在下方「人員與時薪」新增人員」。
5. 選到找不到的人員 →「找不到這位人員（可能已經刪除），請重新選擇」。
   - 只有**修改模式，而且就是那筆記錄原本的人員**時才放行。
6. 等級不是數字 →「填等級」。等級用 `parseInt` 讀取，小數會被捨去。
7. 獲得% 不是數字 →「填獲得 %」。
8. 計費時數是負數 →「計費時數不能是負的」。

### 新增

- id 是 `"s" + Date.now()`，`enabled: true`。
- 新增後記錄表翻到那一筆所在的頁（`focusId`）。
- 等級表沒有這一級時，用紅字提醒「還沒登錄經驗，到下方對照表補上才算得出時速」。記錄照樣新增。
- 存好後清空獲得%、計費時數、備註。日期、起迄、人員、等級保留，方便連續登錄。

### 修改

- 在記錄表按「改」：表單帶入那筆的內容，按鈕變成「儲存修改」，顯示「取消編輯」，畫面捲到最上方。
- 儲存時用表單的值覆蓋那筆記錄。id 和啟用狀態不變。
- 儲存、取消、刪掉正在修改的那筆，或換掉整份資料時，都會回到新增模式（`resetEditUI()`）。
- 刪掉正在修改的那筆時，表單提示「正在修改的那筆已刪除，表單改回新增記錄」。
- 儲存時找不到那筆記錄（已被刪掉），提示「找不到要修改的記錄，表單改回新增記錄」，不會出錯。

### 人員選單（`fillWorkerSelect`）

- 原本選的人員不在名單裡時（人員被刪掉，或記錄本來就對不到人），**保留原本的 id**，顯示成「（找不到這位人員：id）」。**不能讓瀏覽器自動跳到第一位**。
- 修改模式下，記錄原本的人員如果找不到，會一直留在選單上，改選別人之後還能選回來。
- 修改一筆沒有人員（workerId 空白）的記錄時，選單保持空白，不能自動選第一位。
- 新增模式下人員全部刪光時，不保留「找不到」的選項；新增人員後直接選到他。
- 回到新增模式時，如果選的是找不到的人員，選單回到預設的第一位。

### 計費時數欄（`syncBhField`）

- 選到勾了「計費」的人員時顯示，選到不計費的人員時隱藏並清空。
- 選到找不到的人員，或修改沒有人員的記錄時，照樣顯示，不清空。因為不知道是不是計費的人員，清空會讓記錄原本的計費時數不見。

## 設計決策

- **人員選單不能悄悄換人**：以前刪掉人員後，選單自動跳到第一位，一按「儲存修改」，那筆記錄就變成別人的，計費時數也被清掉。
- **計費時數只對計費人員有意義**：自己練的時段不需要這個欄位。
- **存好後保留大部分欄位**：通常會連續登錄同一天、同一級的多個時段。

## 相關程式

`readForm()`、`validate()`、`#btnSave` 的 click 事件、`#btnCancel`、`resetEditUI()`、`fillWorkerSelect()`、`syncBhField()`、`formMsg()`；記錄表的 `[data-edit]` 事件。

## 修改時要檢查

- 新增、修改、取消、刪掉正在修改的那筆，各走一次。
- 修改時刪掉那筆的人員，再儲存：人員和計費時數都要保持原樣。
- 修改一筆沒有人員的記錄，再讓畫面重畫（例如勾選啟用）：選單要保持空白。
- 計費人員、非計費人員之間切換時，計費時數欄的顯示是否正確。
