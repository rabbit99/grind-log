# 人員與時薪

## 目的

登錄練功的人（例如主要角色與第二個角色，或有時薪的人員），以及（啟用「計費與成本」模組時）他們的時薪、是否計費。記錄表靠這裡的資料計算費用。

## 介面

「練功記錄」頁右欄最下方的摺疊面板「人員與時薪」`#tblWorkerEdit`：

- 每一列：名稱、時薪、計費（勾選框）、備註、「刪」。**時薪、計費兩欄只在「計費與成本」模組開啟時顯示**（預設關閉，見 [cost-module.md](cost-module.md)）。
- 面板最上方是模組的開關 `#costToggle` 與說明 `#costNote`。
- 「新增人員」按鈕 `#btnAddWorker`。

## 行為規則

- **行內編輯**：改完離開輸入框（change 事件）才寫入並存檔。
  - 時薪用 `parseFloat`，不是數字時存成 0。
  - 計費的勾選框改了立刻生效。
- **新增人員**：id 是 `"w" + Date.now()`，名稱「新人員」，時薪 0。模組開啟時預設勾選計費（以前的行為）；模組關閉時預設不計費，免得新增人員就讓自動判斷把模組打開。
- **刪除**：一律先確認，並寫出名稱（空白時是「（未命名）」）。
  - 這位人員有記錄時，會寫出筆數，並說明「刪除後那些記錄會找不到人員」。
  - 模組開啟、而且是計費人員、時薪不是 0 時，另外說明「費用也會變成 0（累計花費跟著減少）」。
  - **刪人員不會刪記錄**：那些記錄的人員會變成「?」，費用變成 0。
- **人員顏色**依在名單中的位置分配，6 色循環。刪掉前面的人員，後面的人員顏色會跟著變。
- **日薪要自行換算成時薪**，例如 1600 ÷ 8h = 200。

## 邊界情況

- **沒有 id 的人員**（手改或舊版匯入檔）：讀入時自動編號成 `w-noid-1`、`w-noid-2`…，可以正常修改。規則見 [format.md](../format.md#讀入時的整理)。
- **人員刪掉後**：記錄表的表單遇到這些記錄時，人員選單顯示「（找不到這位人員：id）」，見 [session-form.md](session-form.md#人員選單fillworkerselect)。

## 設計決策

- **刪人員前一律確認**：以前沒有記錄的人員刪除時不會確認；現在統一確認，而且寫明影響範圍，特別是費用會歸零。
- **計費時數只對計費人員有意義**：勾掉「計費」後，表單不再顯示計費時數欄，費用也不計算。

## 相關程式

`renderWorkerEdit()`；`#tblWorkerEdit` 的 change、click 事件；`#btnAddWorker`；`#costToggle`；`workerOf()`、`colorOf()`、`costOn()`。

## 修改時要檢查

- 模組開啟時，改名稱、時薪、計費後，記錄表、人員效率表、經驗條的費用是否跟著變。
- 刪掉有記錄的計費人員：確認框的說明是否正確；刪除後記錄表顯示「?」、費用是 0。
- 表單正在修改某筆記錄時刪掉它的人員（見 session-form.md）。
