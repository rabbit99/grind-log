# 自動儲存與讀不出資料時的保護

## 目的

資料存在瀏覽器的 localStorage，每次修改自動儲存。遇到存的內容讀不出來、或寫不進去時，**不能讓使用者的資料悄悄消失**。

## 自動儲存

- 每次修改資料都會呼叫 `persist()`，把整份資料寫進 `grind-log/v1`，並更新 `meta.updatedAt`。
- 頁首右上 `#saveState` 顯示「已存到這台電腦」，2.2 秒後消失。
- 寫入失敗（空間不足，或瀏覽器不允許）時顯示「無法自動儲存，請用「匯出 JSON」保留資料」。
- `persist()` 回傳有沒有真的寫進去。

## 載入

- `grind-log/v1` 不存在時，顯示示範資料（`seed()`），但不寫入，要等第一次修改才寫。
- 瀏覽器不允許使用 localStorage 時，一樣顯示示範資料。
- 讀得出來時，經過 `normalize()` 整理。**載入時的整理不刪任何東西**，只做不會掉資料的轉換，見 [format.md](../format.md#讀入時的整理)。

## 讀不出資料（JSON 壞掉）

`load()` 解析失敗時：

1. **不改用示範資料**。否則使用者一操作就會存檔，把原本的資料蓋掉。
2. 把原文備份到 `grind-log/v1:unreadable`：
   - 那一格已經有另一份不同的內容時，另存成 `grind-log/v1:unreadable-<時間戳>`。
   - 同一份原文已經備份過（不論哪一格）就不再寫，重新整理不會越存越多份。
   - 空間不足、備份失敗時，`saved = false`。
3. 設定 `loadProblem = {msg, saved, raw}`，畫面顯示空白資料。
4. **暫停自動儲存**：`loadProblem` 存在時，`persist()` 不寫入，狀態列顯示「原本的資料讀不出來，自動儲存已暫停」。

### 紅框提示 `#loadBanner`

- 位置在頁首和頁籤之間，兩個頁籤都看得到，不會被其他訊息蓋掉。
- 內容：
  - 讀不出來，以及原文有沒有備份。
  - 自動儲存暫停中。
  - 救回方法：下載原始內容 → 用文字編輯器修好 → 匯入 JSON。「匯出 JSON」匯出的是畫面上的資料，不是原文。
  - 什麼時候恢復自動儲存。
  - 最下方是錯誤訊息，例如 JSON 解析錯誤的位置。
- 全部用 `textContent` 產生，原文和錯誤訊息不會被當成 HTML。
- **「下載原始內容」** `#btnDownloadRaw`：從記憶體下載原文（`loadProblem.raw`），所以就算備份寫入失敗也下載得到。

### 恢復自動儲存

只有使用者**主動換掉整份資料**時才恢復：匯入 JSON、Electron 開檔、還原示範資料、清空全部。

- 這幾個動作在讀不出資料的期間都會先確認，提醒先下載原始內容，見 [file-io.md](file-io.md#確認框的內容)。
- 一般的新增、修改、刪除都不會恢復，因為那些修改不會存下來，原文也就不會被蓋掉。

`resumeSaving()` 的流程：

1. 清掉 `loadProblem`，嘗試 `persist()`。
2. 寫入成功：提示收起，恢復正常。
3. 寫入失敗：
   - 原文**沒有**另外備份（`saved = false`）：原文還在 `grind-log/v1` 裡，是唯一的一份。
     - 把 `loadProblem` 放回去，並標記 `writeFailed`。
     - 提示和「下載原始內容」留著，繼續暫停自動儲存。
     - 提示和狀態列改成說明「寫不進這台電腦」，畫面上的新資料要用「匯出 JSON」另存。
   - 原文已經備份：原文是安全的，照使用者的選擇恢復自動儲存，只用紅字說明這次寫不進去。

## 設計決策

- **載入不能掉資料**：載入時使用者看不到任何訊息，所以任何「略過」「刪除」都只能在匯入時做，而且要回報。
- **讀不出來時暫停存檔，而不是換成示範資料**：開發匯入檢查時實際重現過這個問題。舊版遇到讀不懂的資料會改用示範資料，下一次存檔就把 160 筆真實記錄蓋成 8 筆示範記錄。
- **提示常駐**：用一般訊息顯示的話，下一則訊息就會把它蓋掉。
- **寫不進去時只在原文沒備份時繼續暫停**：保護唯一的一份原文；已經備份時則尊重使用者剛換上的資料。

## 修改時要檢查

- 在 localStorage 放一份壞掉的 JSON 再開啟：提示出現、原文有備份、操作不會寫入、下載的內容和原文相同。
- 讀不出資料時匯入：取消就不動作；確定之後提示收起、恢復存檔。
- 模擬寫入失敗（覆寫 `Storage.prototype.setItem`）：原文沒備份時繼續暫停，原文有備份時恢復。
- 測完要清掉 `:unreadable*` 這些備份，並把預覽的資料還原，見 [development.md](../development.md#測試方法)。
