隱私權政策

Grind Log 練功記錄　最後更新：2026-10-09

Grind Log 練功記錄（以下稱「本工具」，網址 https://rabbit99.github.io/grind-log/）是在瀏覽器裡執行的網頁工具，用來記錄練功時段，並計算效率與成本。本工具沒有後端伺服器、沒有會員系統，也沒有廣告或流量分析追蹤。

你的資料存在哪裡

  • 你輸入的記錄存在你自己瀏覽器的儲存空間（localStorage），只在那台裝置上。
  • 同一個儲存空間裡還會存：介面設定（例如每頁筆數）、資料讀不出來時的原文備份；使用同步功能時，另外存試算表的 ID、同步狀態，以及「用雲端的」取代這台資料之前另存的舊資料備份。
  • 使用「Google 試算表同步」時，資料會另外存到你自己的 Google 雲端硬碟裡的一份試算表「練功記錄（Grind Log）」。從試算表讀回來的資料，也會存進這台裝置的儲存空間。
  • 資料直接在你的瀏覽器和 Google 之間傳送，全程使用 HTTPS 加密，不經過本工具開發者或任何第三方的伺服器。開發者看不到、也不保留你的任何資料。
  • 資料會一直保留，直到你自己刪除，見下方「刪除資料與撤銷權限」。

Google 使用者資料的使用方式

只有在你按下「連結 Google 帳號」並同意後，本工具才會存取你的 Google 資料：

  • 只要求一個權限：https://www.googleapis.com/auth/drive.file。這個權限只能存取本工具自己建立的檔案，看不到你雲端硬碟裡的其他檔案。
  • 唯一的用途是建立、讀取、更新上述那份試算表，讓你的不同裝置共用同一份存檔。
  • 不讀取你的姓名、電子郵件、聯絡人，或其他 Google 帳號資料。
  • Google 核發的存取權杖只放在瀏覽器的記憶體裡，只用來向 Google 的 API 證明你的授權；關閉頁面就消失，不會寫進儲存空間，也不會交給 Google 以外的任何人。
  • 不會出售或轉移 Google 使用者資料，不用於廣告，也不用來訓練人工智慧模型。
  • 本工具使用及轉移從 Google API 取得的資訊時，會遵守 Google API 服務使用者資料政策，包括其中的「有限使用」規定。

第三方服務

  • Google 登入元件（accounts.google.com）在你按下「連結 Google 帳號」按鈕時載入；已經連結過的話，每次開啟頁面時就會載入。沒有使用同步功能的人不會載入。Google 如何處理資料，請見 Google 隱私權政策。
  • 本工具的網頁由 GitHub Pages 提供，GitHub 可能為了安全與維運記錄一般的連線資訊（例如 IP 位址）。請見 GitHub 一般隱私權聲明。
  • 頁尾的「支持作者」（設定後才會出現）是連到外部網站的連結，本站不會因此傳送任何資料給對方；點進去之後的資料由對方網站依其政策處理。

刪除資料與撤銷權限

  • 刪除這台裝置上的所有資料：清除瀏覽器裡這個網站的資料，上面提到的各種備份也會一起刪除。
  • 本工具的「清空全部」只會清掉記錄、人員和等級表，不會刪除備份。已連結 Google 試算表時，雲端的試算表也會在同步時跟著變成空白（可以從試算表的「檔案 → 版本記錄」找回）。
  • 刪除雲端的資料：在 Google 雲端硬碟刪除「練功記錄（Grind Log）」試算表，並清空垃圾桶。如果曾經刪掉後又重新建立過，雲端硬碟裡可能有好幾份，請全部刪除。
  • 撤銷本工具存取 Google 的權限：到 Google 帳戶的「第三方應用程式和服務」移除本工具。在本工具按「中斷連結」時，如果這次開啟頁面後登入過 Google、而且還沒超過約 1 小時，也會一併撤銷。

Privacy Policy (English summary)

Last updated: 2026-10-09

  • Grind Log is a browser-only web app. It has no backend server, no user accounts, and no ads or analytics.
  • Your records are stored in your browser's localStorage, together with UI settings, recovery backups and, when sync is on, the spreadsheet ID, sync state and a backup of local data replaced by cloud data. If you turn on Google Sheets sync, your records are also stored in a spreadsheet in your own Google Drive, and data read from it is stored in localStorage on that device.
  • Data goes directly between your browser and Google over HTTPS. The developer never receives or keeps any of your data. Data is kept until you delete it.
  • The only Google scope requested is https://www.googleapis.com/auth/drive.file, which gives access only to files this app created. It is used solely to create, read and update that one spreadsheet so your devices can share the same data.
  • The app does not read your name, email address, contacts or any other Google account data. Access tokens are kept in memory only, are sent only to Google APIs, and are never stored or shared with anyone else.
  • Google user data is never sold, transferred, used for advertising, or used to train AI models. Grind Log's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
  • The Google sign-in library (accounts.google.com) is loaded only when you press the connect button, or on every page load once you have connected. See the Google Privacy Policy. The site is hosted on GitHub Pages, which may log basic connection information such as IP addresses; see the GitHub General Privacy Statement.
  • To delete all data on a device, clear this site's data in your browser. The in-app "清空全部" (Clear all) only clears records, workers and levels, not backups; when sync is on, the spreadsheet also becomes empty at the next sync (recoverable from its version history). To delete cloud data, delete the spreadsheet from Google Drive (including any copies) and empty the trash. To revoke access, remove the app at Google Account → Third-party apps & services.
  • The "support the author" link in the page footer (shown only once it is configured) is a plain link to an external site. This app sends no data to that site; whatever happens after you click is handled by that site under its own policy.
  • If this policy changes, this page and the date above will be updated.
  • Contact: GitHub Issues.
