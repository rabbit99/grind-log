# Grind Log — 練功記錄與效率分析

把「每時段獲得幾 %」變成可跨等級比較的真實效率與成本。

三種用法共用同一份 `index.html` 與同一種 JSON 格式（見 `FORMAT.md`）。

---

## 用法 1：直接開網頁（最快，零安裝）

雙擊 `index.html`，或用瀏覽器開啟。

- 資料自動存在瀏覽器的 localStorage，關掉再開還在
- 已預載你 8/20–8/30 的 22 筆記錄當範例
- 用「匯出 JSON」備份，「匯入 JSON」還原

> 因為存在瀏覽器裡，換電腦或清快取會不見。長期使用請定期匯出 JSON。

---

## 用法 2：Electron 桌面程式

多了真正的開檔／存檔（存成電腦上的 `.json`），資料不綁瀏覽器。

```bash
cd grind-log
npm install
npm start
```

第一次 `npm install` 會下載 Electron，約 100–200 MB，需要網路。裝完之後即可離線使用。

介面右下多出「開啟檔案 / 儲存到檔案」，選單也有 `檔案 → 開啟…（Ctrl+O）`、
`另存新檔…（Ctrl+S）`。

> Chrome / Edge 在**瀏覽器裡**也有這兩個按鈕（File System Access API），不必裝 Electron。
> 開過或存過一次之後會記住那個檔，再按「儲存到檔案」就直接覆寫，不再跳對話框；
> 要換檔按「解除連結」。Firefox / Safari 沒有這個 API，按鈕不會出現，請用匯出／匯入 JSON。

打包成 exe（選用）：

```bash
npm install --save-dev electron-builder
npx electron-builder --win --x64
```

---

## 用法 3：接回試算表

「匯出 CSV」會輸出扁平化的時段記錄，含所有推導欄位（時數、每小時經驗、
每小時 %、費用、每百萬經驗成本），可直接丟進 Excel 或 Google Sheets 樞紐分析。

CSV 帶 BOM，中文在 Excel 不會亂碼。

## 介面說明

**上方經驗條**：目前等級的進度，依人員分色。每一段是一個時段，滑過去看明細。

**人員效率表**：綠色是該欄最佳、紅色是最差。看「每百萬經驗成本」而不是
「每 1% 成本」—— 前者才能跨等級比價。

**記錄表**：滑到該列會出現「改／刪」。等級旁邊的紅色「推」字表示該等級的
升級經驗是推估值，不是實測。

最左邊的「啟用」勾選框控制該筆要不要列入統計。取消勾選後那一列會變灰，
資料還在、也還看得到推導數字，但經驗條、人員效率、時數與費用都會跳過它。
標題會顯示還有幾筆被停用。

「計費」欄是實際付錢、也實際在練的時數。真人代練的時段含休息，例如時段
10:00–18:00 但只算 7 小時 —— 這時「時數」顯示 8.0、「計費」顯示金色的 7.0，
費用和每小時經驗都用 7 去算。留空就跟時段一樣，數字不會有任何變化。

左邊表單的「計費時數」欄位只有在選到**有勾「計費」的人員**時才會出現。

表頭「啟用」左邊那個框是整頁開關：勾起來啟用這一頁全部，取消則整頁停用，
只影響目前這一頁。這一頁有開有關時它會顯示成半格。

記錄多的時候表格下方有分頁，可選每頁 10／20／50 筆，頁碼在右邊。每頁筆數會
記住，下次開啟沿用。新增一筆之後會自動翻到那筆所在的頁。

**人員與時薪**：新增打手要先在這裡登錄，記錄表才抓得到時薪。日薪請自行
換算成時薪（例：1600 ÷ 8h = 200）。取消「計費」則不列入費用統計。

**等級經驗對照表**：可信度標成「推估」的等級會在記錄表顯示紅字提醒。
之後取得實測值直接覆蓋，所有歷史記錄的經驗數字會一起重算。

## 已知限制

- 一個時段若中途升級，請拆成兩筆分別填等級，否則經驗換算會有誤差
- 沒有多角色／多帳號的概念，一份檔案記一隻角色；要記多隻就存多份 JSON
- 沒有雲端同步，跨裝置請自行搬 JSON 檔
