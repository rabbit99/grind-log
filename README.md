# Grind Log — 練功記錄與效率分析

把「每時段獲得幾 %」變成可跨等級比較的真實效率與成本。

三種用法共用同一份 `index.html` 與同一種 JSON 格式（見 [docs/format.md](docs/format.md)）。

線上版：https://rabbit99.github.io/grind-log/

---

## 用法 1：直接開網頁（最快，零安裝）

打開上面的線上版，或雙擊 `index.html` 用瀏覽器開啟。

- 資料自動存在瀏覽器的 localStorage，關掉再開還在。每個瀏覽器、每台電腦各自一份，看不到別人的資料。
- 第一次開啟時會顯示示範資料（3 天、8 筆記錄，人員「我」和「代練」）。
  - 按「還原示範資料」可以回到這個狀態。
  - 按「清空全部」會全部歸零。
- 匯入時會先檢查並整理格式（數字字串轉數字、日期補零等），匯入訊息會列出整理了什麼。
  檔案有問題時會退回原本的資料，不會在「匯入失敗」時把你的記錄換掉。
- 瀏覽器裡存的資料讀不出來時，不會換成示範資料：頁首會顯示紅框提示並暫停自動儲存，
  可以按「下載原始內容」把原文存下來，修好後再匯入。
- 用「匯出 JSON」備份，「匯入 JSON」還原。

> 因為存在瀏覽器裡，換電腦或清快取會不見。長期使用請定期匯出 JSON，或用下面的 Google 試算表同步。

### Google 試算表同步（多裝置共用存檔）

在「檔案」面板按「連結 Google 帳號」，存檔會放到**你自己的 Google 雲端硬碟**，是一份試算表「練功記錄（Grind Log）」。
手機、電腦只要登入同一個 Google 帳號，就能共用同一份存檔。

- App 只能存取它自己建立的這份試算表，看不到你雲端硬碟裡的其他檔案；資料不會經過任何第三方伺服器。
- 連結後，每次修改會自動上傳。
- 開啟頁面時按一次「同步」取得最新資料；Google 的權限大約 1 小時過期，到時再按一次。
- 兩台裝置都改過時會先問你要用哪一份，不會悄悄蓋掉。
  - 被取代的雲端版本可以從試算表的「版本記錄」找回。
  - 被取代的這台資料可以按「下載這台的舊資料備份」取回。
- 也可以直接在試算表裡看或修改資料。
  - 起、迄時間請填小時數字（例如 10.5），不要填 10:30。
  - 獲得% 直接填數字（例如 5），不要填 5%。
  - 工作表或欄位名稱被改掉時，App 不會拿它取代你的資料，會請你選擇重新寫入，或到「版本記錄」還原。
- 已連結時，匯入 JSON、還原示範資料、清空全部都會連雲端的存檔一起換掉，確認框會提醒。
- 請用 Chrome、Safari 等一般瀏覽器開啟。LINE、Facebook 這類 App 裡的內建瀏覽器會擋 Google 登入。
- Electron 桌面版目前不支援這個功能。

## 用法 2：Electron 桌面程式

多了真正的開檔／存檔（存成電腦上的 `.json`），資料不綁瀏覽器。

```bash
npm install
npm start
```

第一次 `npm install` 需要網路下載 Electron。裝完之後即可離線使用。

左欄「檔案」面板會多出「開啟檔案／儲存到檔案」，選單也有「檔案 → 開啟…（Ctrl+O）」、
「另存新檔…（Ctrl+S）」。瀏覽器版不會顯示這兩個按鈕，請用匯出／匯入 JSON。

打包成 exe（選用）：

```bash
npm install --save-dev electron-builder
npx electron-builder --win --x64
```

## 用法 3：接回試算表

「匯出 CSV」會輸出扁平化的時段記錄，含所有推導欄位（時數、每小時經驗、
每小時 %、費用、每百萬經驗成本），可直接丟進 Excel 或 Google Sheets 樞紐分析。

CSV 帶 BOM，中文在 Excel 不會亂碼。任何一格的文字以 `=`、`+`、`-`、`@`（含全形）開頭時，
前面會加一個 `'`，避免被試算表當成公式執行；數字（包括負數）照原樣輸出。

## 介面說明

標題下方的頁籤切換「練功記錄」「每日進度」「練功計畫」三個頁面，選擇會記住。

**練功記錄頁**

- **經驗條**：目前等級的進度，依人員分色，每一段是一個時段。
  - 「本級投入」的天數是**時數 ÷ 24**，也就是等於幾天的全天候練功，不是日曆天數。
- **記一筆時段**：
  - 跨午夜直接填（23 到 5，時數算成 6）。
  - 中途升級請拆成兩筆。
  - 選到計費的人員時，才會出現「計費時數」欄：真人代練的時段含休息，例如 10:00–18:00 但只算 7 小時。
- **人員效率表**：每小時經驗最高的標綠色；每百萬經驗成本最低的標綠色、最高的標紅色。
  - 看「每百萬經驗成本」而不是「每 1% 成本」，前者才能跨等級比價。
- **記錄表**：
  - 滑到那一列會出現「改／刪」；手機上一直顯示。
  - 最左邊的「啟用」控制那一筆要不要列入統計，表頭的框是整頁開關。
  - 等級旁的紅色「推」表示升級經驗是推估值。
  - 可選每頁 10／20／50 筆。
- **人員與時薪**：新增打手要先在這裡登錄。日薪請自行換算成時薪（例：1600 ÷ 8h = 200）。取消「計費」則不列入費用統計。
- **等級經驗對照表**：可信度標成「推估」的等級會顯示紅字提醒；之後取得實測值直接覆蓋，所有記錄會一起重算。

**每日進度頁**

- 一天一列，0–24 點的時間軸上依**真實起訖**畫出每個時段，按人員分色。
  - **空白處是「沒有記錄」，不代表沒人練**。
  - 整天沒有記錄的日子會標「無記錄」。
  - 停用的時段顏色變淡；跨午夜的時段畫到 24 點為止，右端標 ↪。
- 一天跨兩個等級時，獲得%分級列出、不相加。
- 「當前%」是當天結束時該等級已累積的 %。已經升上去的等級，登錄的時段加總不到 99.5% 時標紅字「缺」，代表有時段沒登錄。
- 這一頁只看不改，修改都在「練功記錄」頁。

**練功計畫頁**

把「想練到幾級」拆成一張具體的時段表，告訴你每個時段該練到哪裡。

1. 填目前等級與 %（可按「從練功記錄帶入」）、目標等級與 %（填 0 就是升到該級）、起日、期限（幾天或幾個月）、每週哪幾天的幾點到幾點可以練（最多 4 組，時間填小時、15 分鐘的倍數，不能跨午夜），以及預估每小時經驗（預設帶入你的歷史時速，可以改）。
2. 按「產生計畫」。上方摘要會告訴你總共需要多少經驗、每小時要多少，並用綠字／紅字告訴你照預估時速能不能準時達成；下方是每個時段的目標與「結束時該到哪個位置」。
3. 時段進行中那一列會標「進行中」；時段結束後，按「完成」或「沒練」做記錄（按錯了按「改」清掉）。摘要會顯示完成度、落後幾個時段，以及剩下的時段要多快才補得回來。
4. 想改條件：展開「修改條件」按「更新計畫」。已經標記過、而且時間沒變的時段會保留標記；會被清掉時會先問你。

注意：計畫裡的數字是依你輸入的時速**估算的目標**，不是實際獲得的經驗；實際獲得多少 %，請照舊記在「練功記錄」頁。計畫會跟著匯出 JSON 與 Google 試算表同步；匯入、還原示範資料、清空全部這類會換掉整份資料的動作，在有計畫時會先確認。

每個功能的完整規則見 [docs/features/](docs/features/)。

## 已知限制

- 一個時段若中途升級，請拆成兩筆分別填等級，否則經驗換算會有誤差。
- 練功計畫：每週時段不能跨午夜（要拆成兩組）、完成／沒練要等時段結束後才能標、一次只有一份計畫、沒有通知提醒。細節見 [docs/tech-debt.md](docs/tech-debt.md)。
- 沒有多角色／多帳號的概念，一份檔案記一隻角色；要記多隻就存多份 JSON。
- 跨裝置共用請用 Google 試算表同步（Electron 版不支援，要自行搬 JSON 檔）。
- 同時開兩個分頁編輯時，後存的會蓋掉先存的。其他技術細節見 [docs/tech-debt.md](docs/tech-debt.md)。
